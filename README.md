# Key Event Logger

C# Windows Forms ile yaptığım, uygulama penceresi içindeki klavye olaylarını takip eden basit bir program.

## Kullanılan Teknolojiler
- C#
- Windows Forms
- .NET 8

## Özellikler
- Temel pencere ve arayüz tasarımı

## Çalıştırma
Projeyi Visual Studio ile açıp F5'e basarak çalıştırabilirsiniz.
